# ADR-0005: M3 有界多轮上下文

日期: 2026-07-27  状态: 已采纳

## 决策

- 已完成状态可在同一 run_id 开启下一轮；暂停态只允许 `resume()`，失败态拒绝续聊。
- 完整消息始终保留在 `RunState`，仅 ReAct prompt 使用增量摘要和最近消息。
- 摘要复用当前 `ModelPort`，不增加 Context/Embedding 端口或第二套重试。
- 长工具结果由 `ToolPort` 包装器按 SHA-256 外置为文本文件，不修改 MCP adapter。

## 原因

这三处改动分别落在已有状态、Planner 和 ToolPort 组合点上，已足以阻止正常多轮历史与长工具
结果无限膨胀，无需引入 LangGraph、对象存储或额外上下文框架。

## 后果与迁移条件

- checkpoint 文件按 turn/step 命名；`latest.json` 和旧版内容继续兼容。
- 摘要失败沿模型错误路径传播，完整审计历史仍可用于恢复和重建。
- 单条超过上限的用户输入不在 M3 保证范围；出现真实需求时再增加输入分块。
- artifact 目前是本机内容寻址文件；服务化或多机共享时再迁移对象存储。
